# askiical

ASCII 유닛으로 **한 글자**를 짓는 타이포그래피 웹 시뮬레이터입니다. 문자 유닛 사이에 직접 그리거나 SVG에서 가져온 **커스텀 벡터 글리프**를 섞을 수 있습니다.

빌드 과정이 없는 정적 페이지입니다.

```sh
npx http-server -p 8080 .   # 또는 python3 -m http.server
# http://localhost:8080
```

## 구조

| 파일 | 역할 |
| --- | --- |
| `index.html` | 레이아웃과 글리프 편집기 대화상자 |
| `style.css` | UI 스타일 |
| `core.js` | 노이즈·블러, 글리프 지오메트리(Path2D), SVG 가져오기, 기본 글리프 |
| `theme.js` | 색 테마: 팔레트 프리셋, OKLab 보간 색표, 조화 팔레트 생성 |
| `editor.js` | 커스텀 글리프 편집기 |
| `motifs.js` | 키워드 생성기용 모티프 42종 (셀 크기에서 읽히도록 만든 실루엣) |
| `generator.js` | 키워드 → 글리프 생성기 (검색, 스타일 렌더러, UI) |
| `vendor/lucide-icons.js` | Lucide 아이콘 1,877종 (ISC). 생성기를 처음 열 때 불러옴 |
| `tools/build-icons.mjs` | `lucide-static` 패키지로 `vendor/lucide-icons.js`를 다시 만드는 스크립트 |
| `app.js` | 렌더링 파이프라인, 컨트롤, 유닛 패널, 프리셋, 내보내기 |

## 렌더링 파이프라인

1. **래스터**: 글자를 셀당 6×6 슈퍼샘플로 오프스크린 캔버스에 그린 뒤, 셀마다 잉크 비율(coverage)을 구합니다.
2. **톤**: 커버리지에 안쪽 음영(외곽→안쪽, 직선/원형 그라디언트, 노이즈), 바깥 광채, 윤곽 강조, 감마, 대비, 그레인을 적용합니다. 반전하면 글자 바깥이 채워집니다.
3. **램프**: 켜진 유닛마다 실제 셀 크기로 그려서 잉크 밀도를 잽니다.
   - *자동*: 셀 톤에 가장 가까운 밀도의 유닛을 고르고, **혼합 폭** 안에 있는 비슷한 밀도의 유닛끼리는 무작위로 섞습니다. 커스텀 글리프는 이 방식으로 문자 사이에 자연스럽게 끼어듭니다.
   - *수동*: 유닛 칩 순서대로 밝은 톤부터 짙은 톤까지 배정합니다.
4. **페인트**
   - *스탬프*: 배경 위에 유닛을 찍습니다.
   - *녹아웃*: 셀을 채운 뒤 유닛을 배경색으로 뺍니다(Blueprint).
   - *톤에 따라 크기*: 하프톤처럼 톤에 따라 유닛 크기를 바꿉니다.

## 색 테마

왼쪽 **색** 섹션에서 **색 테마**를 켜면 글리프를 하나씩 칠하지 않고, 팔레트의 색 몇 개를 섞어서 칠합니다.

- **팔레트**: 1–8색입니다. 프리셋 10종(리소, 노을, 바다, 숲, 네온, 흙, 캔디, 청사진, 신호, 모노)은 배경도 함께 바꿉니다. 색 칸을 눌러 바꾸고, `+`로 추가하고, `×`로 뺍니다.
- **조화 팔레트**: 유사색·보색·삼각·분할보색·사각 배색 중 하나로 어울리는 팔레트와 배경을 무작위로 만듭니다(OKLCH 기준).
- **순서 섞기 / 뒤집기**: 팔레트 순서를 바꿉니다. 톤·방향·유닛 방식에서는 순서가 곧 색이 퍼지는 순서입니다.

**섞는 방식**

| 방식 | 셀의 색을 정하는 기준 |
| --- | --- |
| 얼룩 | 노이즈 덩어리 (얼룩 크기 조절) |
| 톤 | 셀 톤. 밝은 곳이 첫 색, 짙은 곳이 끝 색 |
| 방향 | 아트보드를 가로지르는 각도 |
| 무작위 | 셀마다 무작위 |
| 유닛 | 램프 순서. 같은 유닛은 같은 색 |

- **색 사이**: *끊어서*는 팔레트 색만 쓰고, *부드럽게*는 OKLab으로 중간색을 만듭니다.
- **칠할 유닛**: 전체, 커스텀 글리프만, 문자만 중에 고릅니다. 나머지 유닛은 기본 유닛 색으로 칠합니다.
- **경계 흩뿌림**: 색 경계를 셀 단위로 흐트러뜨립니다.
- 녹아웃 모드에서는 셀 바탕이 팔레트 색이 되고, 유닛이 배경색으로 빠집니다.
- PNG와 SVG로 내보낼 때 색이 그대로 들어갑니다.

## 커스텀 벡터 글리프

글리프는 0–100 정사각 좌표계를 씁니다.

- **픽셀**: N×N 격자(4–32)의 칸을 칠합니다.
- **펜**: 클릭으로 다각형이나 열린 선을 그립니다.
- **사각형, 원, 직선**: 드래그해서 그립니다(Shift는 정비율).
- **path d 직접 입력**: SVG 경로 명령을 그대로 넣습니다.
- **SVG 파일 가져오기**: `path`, `rect`, `circle`, `ellipse`, `line`, `polyline`, `polygon`을 읽습니다. `viewBox`와 `transform`을 반영하고, 흰색 채움은 배경으로 보고 건너뜁니다.

도형마다 채움 또는 선(두께 지정)을 고를 수 있고, 글리프 전체에 `nonzero`/`evenodd` 채움 규칙을 정할 수 있습니다. TXT로 내보낼 때는 글리프마다 지정한 대체 문자를 씁니다.

## 키워드로 글리프 생성

글리프 패널의 **키워드로 생성** 버튼으로 엽니다. 예를 들어 `원두`를 입력하면 홈이 파인 커피콩 모양이 나옵니다.

**검색 대상은 두 가지입니다.**
- **모티프**: 직접 만든 실루엣 42종입니다(원두, 커피잔, 하트, 꽃, 고양이, 번개 등). 한글과 영어 이름으로 찾습니다. 작은 셀에서도 읽히도록 덩어리 위주로 만들었고, 두께를 올리면 홈이나 잎맥 같은 안쪽 디테일도 함께 굵어집니다.
- **아이콘**: Lucide 아이콘 1,877종입니다. 이름과 태그가 영어라서 한글 키워드는 내장 사전(약 300단어)으로 영어로 바꿔 찾습니다. 사전에 없는 단어는 영어로 검색하세요(예: `bicycle`).

**스타일과 조절 항목**

| 스타일 | 표현 | 조절 |
| --- | --- | --- |
| 면 | 닫힌 도형을 채움 (안쪽 구멍은 evenodd) | 두께 |
| 선 | 모든 윤곽을 선으로 | 두께 |
| 해칭 | 닫힌 도형 안을 평행선으로 채움 | 두께, 밀도(선 간격), 각도, 외곽선 |
| 점묘 | 닫힌 도형 안을 육각 점 격자로 채움 | 두께(점 크기), 밀도(점 간격), 외곽선 |
| 픽셀 | N×N 격자로 래스터화 + 4×4 Bayer 디더링 | 두께, 해상도, 채움 밀도 |

모든 스타일에 크기, 회전, 좌우 반전을 쓸 수 있습니다.

**결과 다루기**
- 미리보기 아래에 잉크 비율이 나오고, 지금 램프에서 어느 유닛 사이에 들어갈지도 함께 보여 줍니다.
- 생성한 글리프는 레시피를 함께 저장합니다. 글리프 카드의 **조절** 버튼으로 나중에 다시 조절할 수 있습니다.
- **편집기에서 다듬기**를 누르면 결과를 일반 편집기로 넘겨 손으로 고칠 수 있습니다. 손으로 고친 뒤에는 레시피가 빠집니다.

아이콘 데이터 갱신:

```sh
npm pack lucide-static && tar xzf lucide-static-*.tgz
node tools/build-icons.mjs ./package
```

## 프리셋

레퍼런스 포스터의 결을 따라 만들었습니다.

| 프리셋 | 구성 |
| --- | --- |
| Signal | 검정 배경, 점 배경장 |
| Blossom | 베이지 배경, `+?$%`, 꽃잎 글리프 |
| Blueprint | 파랑 배경, 격자, 녹아웃, 사각/엑스 글리프 |
| Halftone | 빨간 점, 톤에 따라 크기 |
| Riso | 리소 4색 얼룩 테마 |
| Organic | 성긴 노이즈, 프락투어 |

## 내보내기

- **PNG**: 2400px로 저장합니다.
- **SVG**: 문자는 `<text>`로, 커스텀 글리프는 `<defs>` + `<use>` 벡터로 들어갑니다.
- **TXT / 복사**: 텍스트 아트로 내보냅니다.
- **JSON**: 설정과 글리프 라이브러리를 저장합니다. 불러오기로 다시 열 수 있습니다.

작업 상태는 브라우저 `localStorage`에 자동 저장됩니다. 업로드한 서체 파일은 저장되지 않으니 새로고침 후 다시 올려야 합니다.
