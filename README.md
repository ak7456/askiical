# askiical

ASCII 유닛으로 **한 글자**를 짓는 타이포그래피 웹 시뮬레이터입니다. 문자 유닛 사이에 직접 그리거나 SVG에서 가져온 **커스텀 벡터 글리프**를 섞을 수 있습니다.

빌드 과정이 없는 정적 페이지입니다.

```sh
npx http-server -p 8080 .   # 또는 python3 -m http.server
# http://localhost:8080
```

## 달력 모드

**달력** 섹션에서 켜면 한 달을 종이 한 장에 한 번에 ASCII로 짓습니다. 달 이름과 날짜가 같은 셀 격자 위에 놓이므로 유닛 크기와 위치가 정확히 맞습니다.

**배치와 항목**
- 위쪽에 달 이름 띠가 있고, 그 아래에 7열 날짜 격자가 있습니다. 요일 머리글과 연도는 넣지 않습니다.
- **용지**: A4(210×297), A3(297×420), B4(257×364), B3(364×504), 335×700 중에서 고르고, 세로나 가로로 놓습니다(mm).
- 페이지는 셀 너비(pt)로 용지에 가장 가까운 셀 수가 됩니다. 셀이 정수 개라서 실제 크기는 용지와 1셀 이내로 차이 납니다(3pt 셀이면 1mm 안쪽). 출력 섹션에 용지와 실제 크기를 함께 보여 줍니다.
- 파일 이름에 용지가 들어갑니다(`askiical-2026-09-A3.svg`, 가로는 `-A3-land`).
- 달력 모드를 켤 때 셀 너비가 4pt보다 크면, 작은 날짜가 읽히도록 3pt로 바꾸고 알려 줍니다.
- 조절 항목:
  - 연도, 월, 이전 달 / 다음 달
  - 달 이름 표기: September, SEPTEMBER, Sep, SEP, 9월, 09
  - 달 이름 정렬과 영역 높이
  - 한 주의 시작: 일요일 또는 월요일
  - 날짜 위치(칸 가운데 또는 칸 왼쪽 위)와 크기
  - 바깥 여백, 달 이름과 날짜 사이 간격
  - 달 이름 세로 위치, 날짜 표 세로 위치(행 단위, 0.5행씩). 표를 옮겨도 칸 크기는 그대로입니다.
  - 항상 6주 칸으로 나누기
- **가로선**: "각 주 위에 가로선"을 켜면 날짜 표의 각 주 위에 선을 긋습니다. 선은 실제 날짜가 있는 칸에만 걸칩니다(예: 1일이 목요일이면 첫 주 선은 목요일 칸부터). 비어 있는 6주차에는 긋지 않습니다.
  - *유닛으로 채움*: 선도 날짜 색 테마의 유닛으로 그립니다. 셀 높이보다 가늘면 흐리게 나옵니다.
  - *실선*: 유닛 위에 단색 선을 긋습니다. SVG에서는 `calendar-rules` 그룹의 사각형으로 들어갑니다.
  - 두께(pt)와 세로 위치(행 단위, 0.25행씩)를 조절하고, 실선일 때는 선 색을 따로 고릅니다.
- 날짜는 모두 같은 크기로 그립니다. 가장 넓은 두 자리 숫자가 칸 너비의 90% 안에 들어가도록 맞춥니다.

**색**
- 달 이름 테마와 날짜 테마를 따로 씁니다. 색 섹션의 **편집할 색**으로 두 테마를 오가며 고칩니다. 배경, 유닛, 톤 설정은 공통입니다.
- **특별한 날**은 달 이름 테마로 칠합니다. "일요일 / 토요일을 특별한 날로"를 켜거나, 달마다 날짜를 적습니다(예: `3, 9, 24-26`).
- **월별 팔레트 자동 적용**을 켜면 달을 바꿀 때마다 그 달의 팔레트(`theme.js`의 `MONTHLY`)와 배경을 달 이름 색에 넣습니다. 12달 ZIP 내보내기에서도 달마다 적용되고, 끝나면 원래 색으로 돌아옵니다. 팔레트가 없는 달은 그대로 둡니다.

**내보내기**
- PNG / SVG 버튼은 지금 보이는 달 한 장을 저장합니다(`askiical-2026-09.svg`).
- **12달 SVG (ZIP)**, **12달 PNG (ZIP)**는 같은 설정으로 그 해 12달을 한 ZIP에 묶어 저장합니다.

## 미리보기 확대

아트보드가 크거나 셀이 작으면(예: 달력 모드 3pt), 화면에 다 맞췄을 때 셀 하나가 2–3px밖에 안 되어 유닛이 보이지 않습니다. 이럴 때 아트보드 오른쪽 아래 확대 막대를 씁니다.

- **− / +**: 1.5배씩 줄이고 키웁니다.
- **맞춤**: 아트보드 전체를 봅니다.
- **실제 크기**: 인쇄 크기(1pt = 1/72인치) 그대로 봅니다.
- 숫자는 인쇄 크기 대비 배율입니다.
- **Ctrl/⌘ + 휠**이나 트랙패드 핀치로 커서 위치를 중심으로 확대합니다. 확대한 상태에서는 휠 스크롤이나 드래그로 화면을 옮깁니다.
- **더블클릭**하면 그 자리를 셀 하나가 약 16px이 되도록 확대하고, 다시 더블클릭하면 맞춤으로 돌아옵니다.
- 확대는 미리보기에만 적용되고, 내보내는 파일에는 영향이 없습니다. 확대한 상태에서는 화면에 보이는 셀만 그려서 가볍게 움직입니다.

## 글자 맞춤과 출력 크기

**글자 맞춤** (글자 섹션)
- **서체 기준** (기본): 서체의 높이 범위가 아트보드 높이(세로 셀 수에서 위아래 여백을 뺀 높이 × 글자 크기)를 채우도록 크기를 정하고, 기준선을 항상 같은 행에 둡니다. 높이 범위는 서체가 선언한 어센트·디센트와 `gjpqy()[]Å` 같은 기준 글자의 실제 잉크 중 큰 쪽을 씁니다. 그래서 디센더가 긴 서체도 잘리지 않고, 크기는 지금 글자와 상관없이 일정합니다. 가로 셀 수는 글자의 너비(advance)에 좌우 여백을 더해 자동으로 정합니다.
  - 같은 서체와 같은 설정으로 만든 글자는 대문자 높이, 엑스하이트, 기준선이 셀 단위로 맞습니다.
  - 일러스트레이터에서 아트보드끼리 붙여 놓기만 하면 단어가 됩니다. `I`는 좁게, `M`은 넓게 나옵니다.
- **개별 맞춤**: 예전 방식입니다. 글자마다 윤곽 상자를 아트보드(가로 셀 수 × 비율)에 꽉 맞춥니다.

**출력** (출력 섹션)
- **셀 너비 (pt)**: 셀 한 칸의 실제 너비입니다. 셀 높이는 셀 너비 × 셀 세로 비입니다. SVG와 PNG가 모두 이 값을 따릅니다.
- **PNG 해상도**: 150 / 300 / 600 dpi 중에서 고릅니다. 픽셀 크기는 pt × dpi / 72로 정합니다. PNG에 dpi 정보(pHYs)를 넣어서 일러스트레이터나 포토샵에 놓으면 SVG와 같은 크기로 들어갑니다.
- 너무 커서 브라우저가 만들 수 없는 PNG는 dpi를 낮춰 저장하고 알려 줍니다.
- 섹션 아래에 아트보드 크기를 셀, pt, mm, PNG 픽셀로 보여 줍니다.
- 서체 기준 모드에서 글자 크기를 1보다 키우면 커진 서체 높이와 위아래 여백이 들어가도록 세로 셀 수를 늘립니다. 늘어나는 양은 서체와 설정으로만 정해지므로, 같은 설정으로 만든 글자들은 높이와 기준선이 그대로 같습니다. 1보다 작게 하면 아트보드는 세로 셀 수 그대로이고 글자만 작아집니다.
- 서체 기준 모드에서 디센더(g, j, p, y, Q 꼬리 등)가 아래 여백을 넘으면 그 글자만 아래로 행을 늘립니다. 디센더 밑에는 빈 행을 최소 1행 남깁니다. 위쪽 가장자리와 기준선 행은 바뀌지 않으므로, 일러스트레이터에서는 아트보드 **위쪽 가장자리**를 맞춰 정렬하세요.
- 그래도 글자가 가장자리에 닿아 잘리면(위·옆, 위치 이동 등) 출력 섹션과 아트보드 아래 표시줄에 어느 쪽이 잘리는지 빨갛게 표시합니다.

## 렌더링 파이프라인

1. **래스터**: 글자를 셀당 6×6 슈퍼샘플로 오프스크린 캔버스에 그린 뒤, 셀마다 잉크 비율(coverage)을 구합니다.
2. **톤**: 커버리지에 안쪽 음영(외곽→안쪽, 직선/원형 그라디언트, 노이즈), 바깥 광채, 윤곽 강조, 감마, 대비, 그레인을 적용합니다. 반전하면 글자 바깥이 채워집니다.
3. **램프**: 켜진 유닛마다 실제 셀 크기로 그려서 잉크 밀도를 잽니다.
   - *자동*: 셀 톤에 가장 가까운 밀도의 유닛을 고르고, **혼합 폭** 안에 있는 비슷한 밀도의 유닛끼리는 무작위로 섞습니다. 커스텀 글리프는 이 방식으로 문자 사이에 자연스럽게 끼어듭니다.
   - *수동*: 유닛 칩 순서대로 밝은 톤부터 짙은 톤까지 배정합니다.
4. **페인트**
   - *스탬프*: 배경 위에 유닛을 찍습니다.
   - *녹아웃*: 셀을 채운 뒤 유닛을 배경색으로 뺍니다(Blueprint).
   - *톤에 따라 크기*: 하프톤처럼 톤에 따라 유닛 크기를 바꿉니다.

## 색 테마

왼쪽 **색** 섹션에서 **색 테마**를 켜면 글리프를 하나씩 칠하지 않고, 팔레트의 색 몇 개를 섞어서 칠합니다.

- **팔레트**: 1–8색입니다. 프리셋 10종(리소, 노을, 바다, 숲, 네온, 흙, 캔디, 청사진, 신호, 모노)은 배경도 함께 바꿉니다. 색 칸을 눌러 바꾸고, `+`로 추가하고, `×`로 뺍니다.
- **조화 팔레트**: 유사색·보색·삼각·분할보색·사각 배색 중 하나로 어울리는 팔레트와 배경을 무작위로 만듭니다(OKLCH 기준).
- **순서 섞기 / 뒤집기**: 팔레트 순서를 바꿉니다. 톤·방향·유닛 방식에서는 순서가 곧 색이 퍼지는 순서입니다.

**섞는 방식**

| 방식 | 셀의 색을 정하는 기준 |
| --- | --- |
| 얼룩 | 노이즈 덩어리 (얼룩 크기 조절) |
| 톤 | 셀 톤. 밝은 곳이 첫 색, 짙은 곳이 끝 색 |
| 방향 | 아트보드를 가로지르는 각도 |
| 무작위 | 셀마다 무작위 |
| 유닛 | 램프 순서. 같은 유닛은 같은 색 |

- **색 사이**: *끊어서*는 팔레트 색만 쓰고, *부드럽게*는 OKLab으로 중간색을 만듭니다.
- **칠할 유닛**: 전체, 커스텀 글리프만, 문자만 중에 고릅니다. 나머지 유닛은 기본 유닛 색으로 칠합니다.
- **경계 흩뿌림**: 색 경계를 셀 단위로 흐트러뜨립니다.
- 녹아웃 모드에서는 셀 바탕이 팔레트 색이 되고, 유닛이 배경색으로 빠집니다.
- PNG와 SVG로 내보낼 때 색이 그대로 들어갑니다.

## 문자 유닛 조정

유닛 패널의 **문자 유닛 조정**에서 문자 유닛(알파벳, 숫자, 기호)이 셀 안에 놓이는 방식을 바꿉니다. 커스텀 글리프는 원래 셀 가운데에 맞춰 그려지므로 여기에 영향을 받지 않습니다.

- **세로 맞춤**
  - *대문자 기준* (기본): 대문자 높이의 가운데를 셀 가운데에 둡니다. 대문자와 기호가 커스텀 글리프와 같은 높이에 놓이고, 소문자는 같은 기준선 위에 앉습니다.
  - *글자마다*: 각 글자의 잉크 상자를 셀 가운데에 둡니다. 마침표나 밑줄도 가운데로 옵니다.
  - *서체 기본*: 예전 방식(서체 em 상자의 가운데)입니다. 대문자가 셀 높이의 약 9% 위로 치우칩니다.
- **크기**: 문자 유닛만 키우거나 줄입니다. 커스텀 글리프는 그대로입니다.
- **두께**: 획 바깥으로 같은 색 선을 덧그려 굵게 만듭니다(글자 크기 대비).
- **가로·세로 위치**: 셀 너비·높이 대비로 옮깁니다.
- 잉크 비율(톤 램프)과 아웃라인 SVG에 모두 반영됩니다. SVG에서는 두께가 둥근 모서리 면으로 들어갑니다.

## 커스텀 벡터 글리프

글리프는 0–100 정사각 좌표계를 씁니다.

- **픽셀**: N×N 격자(4–32)의 칸을 칠합니다.
- **펜**: 클릭으로 다각형이나 열린 선을 그립니다.
- **사각형, 원, 직선**: 드래그해서 그립니다(Shift는 정비율).
- **path d 직접 입력**: SVG 경로 명령을 그대로 넣습니다.
- **SVG 파일 가져오기**: `path`, `rect`, `circle`, `ellipse`, `line`, `polyline`, `polygon`을 읽습니다. `viewBox`와 `transform`을 반영하고, 흰색 채움은 배경으로 보고 건너뜁니다.

도형마다 채움 또는 선(두께 지정)을 고를 수 있고, 글리프 전체에 `nonzero`/`evenodd` 채움 규칙을 정할 수 있습니다. TXT로 내보낼 때는 글리프마다 지정한 대체 문자를 씁니다.

## 키워드로 글리프 생성

글리프 패널의 **키워드로 생성** 버튼으로 엽니다. 예를 들어 `원두`를 입력하면 홈이 파인 커피콩 모양이 나옵니다.

**검색 대상은 두 가지입니다.**
- **모티프**: 직접 만든 실루엣 42종입니다(원두, 커피잔, 하트, 꽃, 고양이, 번개 등). 한글과 영어 이름으로 찾습니다. 작은 셀에서도 읽히도록 덩어리 위주로 만들었고, 두께를 올리면 홈이나 잎맥 같은 안쪽 디테일도 함께 굵어집니다.
- **아이콘**: Lucide 아이콘 1,877종입니다. 이름과 태그가 영어라서 한글 키워드는 내장 사전(약 300단어)으로 영어로 바꿔 찾습니다. 사전에 없는 단어는 영어로 검색하세요(예: `bicycle`).

**스타일과 조절 항목**

| 스타일 | 표현 | 조절 |
| --- | --- | --- |
| 면 | 닫힌 도형을 채움 (안쪽 구멍은 evenodd) | 두께 |
| 선 | 모든 윤곽을 선으로 | 두께 |
| 해칭 | 닫힌 도형 안을 평행선으로 채움 | 두께, 밀도(선 간격), 각도, 외곽선 |
| 점묘 | 닫힌 도형 안을 육각 점 격자로 채움 | 두께(점 크기), 밀도(점 간격), 외곽선 |
| 픽셀 | N×N 격자로 래스터화 + 4×4 Bayer 디더링 | 두께, 해상도, 채움 밀도 |

모든 스타일에 크기, 회전, 좌우 반전을 쓸 수 있습니다.

**결과 다루기**
- 미리보기 아래에 잉크 비율이 나오고, 지금 램프에서 어느 유닛 사이에 들어갈지도 함께 보여 줍니다.
- 생성한 글리프는 레시피를 함께 저장합니다. 글리프 카드의 **조절** 버튼으로 나중에 다시 조절할 수 있습니다.
- **편집기에서 다듬기**를 누르면 결과를 일반 편집기로 넘겨 손으로 고칠 수 있습니다. 손으로 고친 뒤에는 레시피가 빠집니다.

아이콘 데이터 갱신:

```sh
npm pack lucide-static && tar xzf lucide-static-*.tgz
node tools/build-icons.mjs ./package
```

## 내보내기

아티팩트 미리보기에서는 다운로드가 막혀 있습니다. 내보내기는 `index.html`을 직접 열거나 웹 서버로 띄워서 쓰세요.


- **PNG**: 셀 너비(pt)와 dpi로 크기를 정하고, dpi 정보를 파일에 넣어 저장합니다.
- **SVG (인쇄용 아웃라인)**: 모든 유닛을 채움 패스로 바꿔 저장합니다. 일러스트레이터에 그대로 열어 인쇄 작업을 할 수 있습니다.
  - 파일에는 `<path>`, `<rect>`, `<g>`만 들어갑니다. `<use>`, `<text>`, 선(stroke), `transform`, `currentColor`는 쓰지 않습니다.
  - 커스텀 글리프는 도형 행렬과 셀 위치를 좌표에 반영합니다. 원호와 2차 곡선은 3차 곡선으로 바꿉니다.
  - 선(stroke)은 둥근 끝·둥근 모서리 그대로 면으로 바꿉니다. 곡선은 15° 이하로 나눈 조각마다 양쪽으로 평행 이동한 3차 곡선(오프셋 곡선)으로 만들어서, 확대해도 곡선으로 남습니다. 선이 곡률보다 굵어 안쪽이 접히는 구간만 잘게 나눈 캡슐로 대신합니다. 조각들을 같은 방향으로 겹친 컴파운드 패스라서, 일러스트레이터에서 한 덩어리로 만들려면 패스파인더 → 합치기를 쓰세요.
  - 문자는 내장 서체(JetBrains Mono, IBM Plex Mono, Space Mono, VT323, Major Mono Display)나 직접 올린 TTF/OTF/WOFF 서체에서 글리프 윤곽을 가져옵니다. 유닛 서체에 없는 문자는 JetBrains Mono → IBM Plex Mono 순서로 찾고, 그래도 없으면(예: 한글 자모) 텍스트로 남기고 알려 줍니다.
  - 레이어는 `background`, `grid`, `cells`(녹아웃 칸), `background-units`, `units-N`(색마다 한 그룹)로 나뉩니다. 별색이나 색 교체 작업을 그룹 단위로 할 수 있습니다.
  - 크기는 pt 단위입니다(`width="…pt"`). 셀 하나가 정확히 셀 너비(pt)가 되므로 일러스트레이터에서 1:1로 열립니다.
- **TXT / 복사**: 텍스트 아트로 내보냅니다.
- **JSON**: 설정과 글리프 라이브러리를 저장합니다. 불러오기로 다시 열 수 있습니다.

작업 상태는 브라우저 `localStorage`에 자동 저장됩니다. 업로드한 서체 파일은 저장되지 않으니 새로고침 후 다시 올려야 합니다.
